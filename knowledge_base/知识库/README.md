# 获客文案知识库 (Knowledge Base)

本目录是【短视频文案工作区】的专属核心大脑与事实真相源。

---

## 一、 知识库运行机制（AI 强制调用原则）

1. **查阅先行**：AI 每次在生成任何短视频脚本、选题、文案或分镜前，**必须无条件首先读取本目录下的所有文件**；
2. **事实优先**：若本知识库中提供了具体的数据、案例、地名、政策或话术金句，文案必须**优先引用并严格对齐**，严禁与知识库冲突或脱离知识库凭空捏造；
3. **空库兜底**：当前若部分模块暂为空白，AI 将遵循 `AGENTS.md` 基础军规创作；用户后续可随时在对应分类下直接追加真实素材，AI 会在下一次对话中自动学习吸纳。

---

## 二、 知识库文件结构分类

| 文件名 | 存放内容与维度 |
|---|---|
| `本地真实案例库.md` | 同城街镇真实业主案例（哪村哪户、安装面积、补贴到账金额、每年租金、实测降温防雨效果） |
| `客户常见异议与金句库.md` | 评论区与私信高频问题（怕背贷款、怕漏水、怕辐射、担心大风刮跑）、本地老百姓大白话反驳金句 |
| `资方政策与收益参数库.md` | 当前最新初装费标准、租金标准、合同年限、施工标准（轻钢立柱规格、防水工艺等） |
| `同行套路与避坑拆解库.md` | 市场上“假租顶真贷款”、“以租代购”等中介常见套路剖析，用于反认知撕套路文案 |
